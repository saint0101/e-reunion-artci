Comment restaurer une sauvegarde ?

Téléchargez le fichier souhaité, copiez-le sur le serveur puis exécutez :

# Restauration complète (base + médias)
python manage.py backup_restore backup_YYYYMMDD_HHMMSS.tar.gz

# Base de données uniquement
python manage.py backup_restore backup_YYYYMMDD_HHMMSS.tar.gz --db-only

# Médias uniquement
python manage.py backup_restore backup_YYYYMMDD_HHMMSS.tar.gz --media-only

# Sans confirmation interactive
python manage.py backup_restore backup_YYYYMMDD_HHMMSS.tar.gz --yes
